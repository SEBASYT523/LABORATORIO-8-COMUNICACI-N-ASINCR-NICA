# Actividad 2 — Cancelación, Reembolso y Validación de Entrega

Desde la carpeta donde está `Escrow_Actividad2.py` ejecuta todas las pruebas con:

```bash
python Escrow_Actividad2.py
```

O ejecuta un caso específico:

```bash
python Escrow_Actividad2.py cancelacion
python Escrow_Actividad2.py reembolso
python Escrow_Actividad2.py sin_despacho
python Escrow_Actividad2.py flujo_normal
python Escrow_Actividad2.py validaciones
```

Los tres primeros son los casos solicitados, los otros dos comprueban que el flujo normal siga funcionando. Cada prueba correcta termina con `COMPROBACIÓN: OK`.
