# Actividad 1 — Atributos de Calidad

Para ejecutar abre una terminal en la carpeta donde está `Escrow_Actividad1.py` y ejecuta:

```bash
python Escrow_Actividad1.py rendimiento
```

Reemplaza `rendimiento` por `disponibilidad`, `confiabilidad`, `seguridad`, `escalabilidad` o `mantenibilidad` para probar cada atributo. Para ejecutar **todas** las pruebas:

```bash
python Escrow_Actividad1.py todos
```

Los resultados se muestran en la terminal.
